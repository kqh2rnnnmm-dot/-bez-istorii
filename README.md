# Без истории

Бесплатный инструмент самоисследования. Статический HTML/CSS/JavaScript: без внешнего backend, API, ключей, сборки и зависимостей сайта.

## Как включить сайт — без кода

1. Откройте репозиторий `kqh2rnnnmm-dot/-bez-istorii`.
2. Нажмите **Settings** в верхнем меню репозитория.
3. В левом меню нажмите **Pages**.
4. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**.
5. В разделе **Branch** выберите **main**, рядом — **/ (root)**.
6. Нажмите **Save**. Когда GitHub закончит публикацию, здесь появится **Visit site** — нажмите её.

Ожидаемый адрес после включения: https://kqh2rnnnmm-dot.github.io/-bez-istorii/ . До включения Pages адрес может показывать 404. Кнопка Visit site в настройках — подтверждение успешной публикации.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что работает

- 13 шагов: рассказ → конкретный эпизод → факты → одна мысль → интенсивность → четыре вопроса → другая формулировка и её основания → вывод → действие → повторная оценка.
- Для каждого поля: что сделать, зачем, пример, что не требуется.
- Пять действующих контекстных подсказок. В многопольном шаге они относятся к последнему выбранному полю; иначе — к первому незаполненному.
- Локальные правила замечают обобщения и предположения о мотивах. Это не ИИ и не проверка истинности рассказа.
- Автосохранение после каждого ввода и выбора. Пауза, продолжение, история, полная карта, скачивание карты в TXT, удаление с подтверждением.
- Поиск повторяющихся тем и фраз минимум в двух завершённых сессиях, без диагнозов. Кризисные сессии исключены.
- Работа на узком и широком экране; клавиатурная навигация и подписи полей.

## Приватность и ограничения

Ответы хранятся в localStorage (`bez-history-v1`) только в данном браузере. Хранилище не зашифровано и не синхронизируется между устройствами. Очистка данных сайта удаляет историю. В приватном режиме она может исчезнуть после закрытия. При нехватке места/недоступности сохранения сайт сообщает об этом; карту можно скачать до закрытия вкладки.

Никаких fetch/XHR, внешних шрифтов, аналитики или библиотек. CSP запрещает исходящие соединения скриптов (`connect-src 'none'`). GitHub получает обычные запросы файлов сайта, но ответы не включаются в запросы, адреса страниц или логи. Внешний источник МЧС и телефон открываются только по действию пользователя. Доступ к самому устройству позволяет прочитать записи.

Старые данные прототипа `bi_sessions_v04` и `bi_draft_v04` переносятся в новую схему без удаления оригиналов. Просмотр старой карты не заменяет текущий черновик. Повреждённые данные не перезаписываются. Изменения из другой вкладки блокируют перезапись до обновления страницы.

## Безопасность

Риск проверяется при вводе во всех полях и перед переходом. При совпадении включается постоянный для этой сессии режим поддержки: вопросы о правдивости мысли и альтернативы остановлены. Есть ручная кнопка «Мне сейчас небезопасно». Никаких автоматических обвиняющих разворотов, в том числе в обычной ветке.

Распознавание по словам несовершенно: возможны пропуски, опечатки и ложные срабатывания. Отсутствие срабатывания не подтверждает безопасность. Сайт не оценивает состояние, не ставит диагнозы, не заменяет помощь специалиста и не вызывает экстренную службу. При реальной непосредственной опасности — 112 в России или местный экстренный номер в другой стране.

Источник номера: https://76.mchs.gov.ru/deyatelnost/poleznaya-informaciya/rekomendacii-naseleniyu/sistema-112

## Файлы и проверка для разработчика

- `index.html`, `styles.css`, `app.js`, `logic.js`, `favicon.svg` — весь сайт.
- `.nojekyll` — выдача статических файлов через GitHub Pages.
- `tests/app.test.cjs` — регрессионные проверки поведения и хранения.
- `tests/serve.cjs`, `package.json` — только необязательный сервер для проверки в среде разработки. Зависимостей нет. GitHub Pages не использует Node/npm.
- `tests/mobile.html` — проверка CSS в окне шириной 375px; это не эмулятор Safari.
- `TESTING.md` — результаты и ограничения проверки.

Сайт можно открыть через `index.html`, но для стабильного сохранения рекомендуется GitHub Pages: поведение localStorage у локальных file:// адресов зависит от браузера. Для разработчика: `node --test tests/app.test.cjs`; необязательный HTTP-сервер — `node tests/serve.cjs`. Пользователю не нужно выполнять команды.
